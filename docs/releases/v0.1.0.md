## SAMA Drum Practice v0.1.0 — First Beta

First TestFlight beta for the SAMA Drum Practice app. An iPad-first practice logging tool for drum students following the San Antonio Music Academy curriculum.

### Highlights

- **5-tab app**: Practice, Music, History, Progress, Settings
- **Real-time session logging** with ostinato grid, tempo/mistake tracking, segment flow, and undo
- **Sheet music viewer** with built-in metronome and 40+ click sounds
- **Progress dashboard** with mastery grid, tempo charts, streak tracking, and practice calendar heatmap
- **Cloud sync** via Supabase with Apple Sign-In
- **CSV export** of all practice data
- **iPad optimized** — landscape split-view, large touch targets, always-dark theme, ADHD-friendly design

### What's Included

| Feature | Details |
|---|---|
| Curriculum | Walking Beat, Eighth Note Exercises, Rhythm Series 1-3 Prep, Practice Pad Fundamentals, Misc |
| Ostinato patterns | Up to 8 per exercise (1A-4A, 1B-4B) |
| Mastery model | Pass (<=3 mistakes, no break) / Mastered (last 10 avg <=1, no breaks) |
| Session features | Notes, video links, segment stats, resume/delete |
| Sync | Automatic on foreground, debounced push on mutations |
| Seed data | Pre-populated from handwritten practice notes |

### Tech

Expo 54 · React Native 0.81 · TypeScript 5.9 · expo-sqlite · Zustand · Supabase · Victory Native + Skia

### Known Limitations

- This is a beta — expect rough edges
- Export requires iOS share sheet (no direct email/save option)
- Progress charts require sufficient practice data to be meaningful
